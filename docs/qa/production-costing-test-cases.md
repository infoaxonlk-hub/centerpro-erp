# Manufacturing valuation and P&L QA

Apply migration 056 after 055 in a test database. Use an active business with Manufacturing, Inventory, Purchases, Sales, Expenses and Payment Reports, an authorized admin, a scoped staff account, two centers and a second business. Read [costing/accounting boundaries](../production-costing-and-profit-loss.md).

| Case | Steps | Expected result |
| --- | --- | --- |
| Selected actual lot | Set raw default purchase price 999. Receive 10 KG into CHEAP at 10 and 10 KG into EXPENSIVE at 30. Manufacture with 4 KG specifically from EXPENSIVE. | Material cost 120, not 40, 80, 999 or the latest/default price. Audit shows the selected lot and movement. |
| Actual operation | Enter 2 actual hours at 5; repeat a separate order with changed hours, rate and consumed quantities. Exercise hourly, KG and batch basis. Use G where appropriate. | Cost changes by actual quantity/time × rate. G converts to KG; count-based inputs are not treated as KG for weight rates. |
| Output shares | Use material 120 + operation 10. Output 3 KG main at 75% and 1 KG by-product at 25%. | Total 130; main allocation 97.50, by-product 32.50, unit costs 32.50. Shares 90% fail with no postings; all zero uses documented quantity fallback. Mixed KG/G converts; weight/count mixtures require explicit shares. |
| Draft | Save the above without completing. Inspect movements, cost entries, expenses, cash/bank postings and P&L. | No stock, valuation, COGS, expense or journal posting. Reopening preserves quantities, sources and shares. |
| Completion and retry | Complete, record output lots/costs and balances, then retry the same completion/save ID. | Material decreases, output inventory increases by allocated value, net inventory rises by conversion costs. No COGS until sale, no duplicate lot/value/payment. Completion snapshot/source links remain immutable. |
| Partial main-product sale | Sell 1 KG of the 3 KG main lot for 100 before adding another earlier lot of the same output. | COGS 32.50; gross profit 67.50; remaining main stock 2 KG valued at 65. By-product 1 KG valued at 32.50 remains inventory. |
| By-product sale | Sell half of the by-product quantity. | COGS uses that output lot's recorded value; the unsold half remains in inventory. Production cost is not expensed in full. |
| External fees | Complete with 2 KG input at 30, operation 2 hours × 5, external fee 3/KG. | Material 60 + labor 10 + service 6 = 76. Each conversion source appears once. An external order's operation field represents additional operations, not a duplicate service charge. |
| Linked labor/service expense | Record labor expense 12 and external service expense 7 using the existing expense flow. Link them to the order above, leaving intentionally different rate-derived estimates. | Conversion cost is 19, replacing the rate estimates. Total cost 79. Existing expense/payment records are unchanged; P&L reclassifies 19 into inventory once. |
| Duplicate/future/foreign source | Link the same expense to operation and external fields, reuse it on another order, select a future-date expense, or send another tenant/center's expense ID directly to save/complete. | Rejected. Existing completed costs are unchanged. Any failed completion leaves input stock, outputs, costs and financial ledgers unchanged. |
| Packing | Consume 2 KG bulk at 32.50/KG, 2 empty bags at 2 each, and 2 hours packing at 3. Produce 2 × 1 KG bags. | Packed inventory cost 75, unit cost 37.50. Selling one bag at 80 gives COGS 37.50 and gross profit 42.50; one bag remains valued at 37.50. Packaging is included once. |
| Reused lot | Add a later, differently priced receipt into an existing source lot, then consume it. | Input uses remaining lot value / remaining lot quantity. Historical receipt prices are unchanged. It does not use the old first price or latest default. |
| Blended purchase return | Receive 10 units at 10 and 10 at 30 into the same lot. Sell 10, then return the original 10-unit/10-price receipt. | Sale COGS is 200. Remaining inventory carrying value 200 leaves on return, historic supplier credit remains 100, and explicit purchase-cost variance is −100. Remaining quantity and value are both zero. |
| Rounding | Produce 3 units with total allocated value 110, then sell 1 and 2 units separately. | Display unit cost 36.666667; exact total COGS is 110, remaining quantity/value zero. No stranded rounding stock value. |
| Returns/cancellations | Return a sold quantity and separately cancel an unreturned sale. Include a return in a later date range. | Exact original lot allocation/value is reversed. P&L revenue and COGS reverse on return/cancellation date. Original sales-line revenue, rather than a mutable due balance, is used. |
| Transfers/scrap/counts | Transfer produced goods between authorized locations, scrap some, and perform an authorized count adjustment. | Transfers preserve lot and value, with no sales COGS. Scrap reduces inventory and appears as scrap loss. Quantity and exact value reconcile between movements and lot allocations. Count movements remain auditable and outside sold-product COGS. |
| Historical migration | Capture stock quantities, costs, completed production and sales before 056, then migrate. | Economic historical values and quantities are unchanged. New six-decimal formatting is not a revaluation. Legacy/unallocated history remains identifiable. Historical costs are not reconstructed. |
| Permissions and licensing | Use staff without report access, without expense access, with only one assigned center, an expired business, and another tenant. Disable Manufacturing/Inventory/Payment Reports as applicable. | Existing permission/module/subscription gates hold. No cross-center or cross-tenant costs/sources/reports are exposed. Unauthorized expense linkage fails. |
| Accounting boundary | Inspect cash/bank subledgers and supplier payables after draft/completion. Review the P&L boundary note. | Completion creates no duplicate cash entries, supplier bills or invented GL accounts. Unlinked conversion charges are clearly identified as accruals; this management report is not represented as a statutory GL. |
