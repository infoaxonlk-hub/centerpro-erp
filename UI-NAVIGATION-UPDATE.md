# UI & Navigation Update

This revision reorganizes the ERP navigation and adds consistent wayfinding.

## What changed

- Sidebar is grouped into **Overview**, **Operations**, **Finance**, **Configuration**, and **Administration**.
- Current module is visually highlighted.
- Sales and Payment Reports expose contextual submenus only while those modules are active.
- Added a consistent **Back** button and breadcrumb bar to dashboard pages and detail screens.
- Purchase/Sales POS screens keep their own full-screen back controls, so no duplicate toolbar is added there.
- Dashboard app cards now follow the same operational order as the sidebar.
- Common button, focus, spacing, and panel styling was normalized for a more consistent ERP UI.
- Mobile/tablet navigation keeps the existing bottom navigation behavior while using the new menu structure.

## Menu order

1. Dashboard
2. Purchases
3. Sales
4. Inventory / Stock
5. Cash & Payments
